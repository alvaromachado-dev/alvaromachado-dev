## 👋 Sobre mim

Sou **Álvaro**, desenvolvedor focado em **automação de processos**. Hoje sou **Programador II no Grupo GPS**, onde cuido de tudo que envolve automação na regional — de robôs que operam sistemas financeiros corporativos a ferramentas que eliminam horas de trabalho manual por semana.

Fora da empresa, faço **freelas de desenvolvimento web** e construo projetos pessoais que vão de RAG com IA a jogos mobile.

```python
class Alvaro:
    def __init__(self):
        self.cargo      = "Programador II @ Grupo GPS"
        self.foco       = ["Automação de processos", "Integração entre sistemas", "Back-end & Web"]
        self.stack      = ["Python", "Flask", "Selenium", "PyAutoGUI", "OpenCV", "Docker", "PostgreSQL"]
        self.aprendendo = ["IA aplicada (RAG)", "FastAPI", "React + TypeScript"]
        self.freelas    = True

    def missao(self) -> str:
        return "Transformar processo manual em processo que roda sozinho. ⚙️"
```

- ⚙️ Automatizo **processos de ponta a ponta**, seja na web, no desktop, via API ou direto no banco de dados. Se tem regra, dá pra automatizar.
- 🔗 Conecto **sistemas que não conversam entre si**: ERPs, portais, planilhas, e-mail, bancos de dados, BI e o que mais aparecer
- 🧩 Escolho a ferramenta pelo problema, de requisições HTTP e Selenium até RPA com visão computacional quando não há outro caminho
- 🌐 Desenvolvo **back-ends, APIs e aplicações web** full stack
- 💼 Aberto a **freelas** e a oportunidades como dev de automação (júnior/pleno)
